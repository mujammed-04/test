## Решения

- Фасовки сделал нативными `radio` в `fieldset`, поэтому выбор работает с клавиатуры и без JS.
- Цены и артикулы хранятся в `data-*` атрибутах. Скрипт только читает разметку и обновляет цену, старую цену, артикул и бейдж скидки. Процент скидки считается автоматически.
- Цены форматирую через `Intl` (`326,40 ₽`, `1 432 ₽`), а изменения объявляются скринридерам через `aria-live`.
- У кнопки есть состояния hover, focus и active, а после нажатия она показывает «Добавлено».
- У каждой фасовки показал цену за 100 г, чтобы была видна выгода крупных упаковок.
- Раскладку меняю через `grid-template-areas`, HTML один для всех экранов:
  - **mobile (375)**: одна колонка, фасовки 2×2, хлебные крошки сворачиваются в ссылку «назад»;
  - **tablet (768)**: заголовок сверху, фото и блок покупки рядом, описание ниже;
  - **desktop (1440)**: фото слева закреплено при прокрутке, вся информация справа.
- Цвета и шрифт взял с teaboom.ru: Open Sans, кремовый `#fefcef`, жёлтый `#f5d730`, светло-зелёный `#e9f2c3`, тёмный `#202020`.
